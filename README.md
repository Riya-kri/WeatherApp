# 🌤️ Weather App

A simple and responsive Weather App built using **React.js** that allows users to search for a location and view its current weather information.

## 🚀 Features

- 🔍 Search weather by location
- 🌡️ Displays current temperature
- 📉 Shows minimum temperature
- 📈 Shows maximum temperature
- 🤗 Displays "Feels Like" temperature
- ☁️ Shows current weather condition
- 📱 Simple and responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Material UI
- Weather API
- Vite

## 📂 Project Structure

The application is divided into three main React components:

- **SearchBox** – Handles location/search input.
- **InfoBox** – Displays the weather information such as temperature, min/max temperature, feels-like temperature, and weather condition.
- **WeatherApp** – Main component that manages the application logic and connects the other components.
